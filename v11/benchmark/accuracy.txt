V11 numerical validation

Final sigmoid approximation
- Common path interval: |x| <= 1.
- Polynomial: 0.5 + x * (c1 + x^2 * (c3 + x^2 * c5)).
- c1 = 0.24998101634651657
- c3 = -0.020677835421401624
- c5 = 0.0017580292406143272
- Any AVX-512 vector containing a lane with |x| > 1 falls back to the existing checked libmvec sigmoid for that vector.
- Dense 1,000,001-point validation grid on [-1,1]: maximum absolute sigmoid error approximately 2.6831e-6.

Stopping semantics
- Training gradients and the lightweight percentage-error metric use the adaptive sigmoid on retained v11 paths.
- If the approximate percentage-error metric indicates that the target may have been reached, v11 recomputes metrics with the existing exact inference path before accepting target success.
- Therefore an approximation-only false-positive target crossing is not accepted.
