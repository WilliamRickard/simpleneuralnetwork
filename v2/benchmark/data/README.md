# Synthetic benchmark data

The benchmark uses deterministic, non-sensitive synthetic data with 11 inputs and one output. Targets are generated by a fixed 11 -> 16 -> 1 sigmoid teacher network. Initial weights are also deterministic.

The large input/output files are generated rather than committed because the 100,000-row text dataset alone is about 16 MB uncompressed.

Generate the exact 100,000-row dataset from the repository root:

```text
python3 v2/benchmark/generate_test_data.py 100000 --out v2/benchmark/data/test_data_100k
```

The generated files should have these SHA-256 hashes:

```text
d9224fabd2436914ca4c8d44a0ead1c3ded09a60876680d81a73e9817144bc40  InputVariables.txt
9faab2ee531df475abe071c8fb17e93a4601076f80d4a6e5e16105f247c4c5b9  OutputVariables.txt
ee3a5fc68fbbd73f5bf8ab86b6df674ceea713ca0a5cec03a217774ed3c9148f  wone.txt
71c59fe59d493d58ded8f0e5f966f5efecdd20e2c444ed922b9c21d98280393a  wtwo.txt
```

For reference, the previously generated ZIP of those four files had SHA-256:

```text
4a8e12008f4ba8273236588819b1fe376938fbffccdb7666785175ea711d908b  test_data_100k.zip
```

`wone.txt` and `wtwo.txt` are checked into this directory because they are small and make the starting point immediately visible. The generator reproduces the same files.
